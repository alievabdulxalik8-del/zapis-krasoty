Политика конфиденциальности

Последнее обновление: сентябрь 2026

1. Какие данные собираются

При записи на услугу через сайт мы собираем минимально необходимые данные: имя, номер телефона и, если вы указали, пожелание к услуге (цвет, форма, дизайн). Мастер также фиксирует выбранную услугу, дату и время визита.

2. Для чего используются данные

  • Для записи на выбранное время и подтверждения визита;
  • Для истории посещений и напоминаний о повторной процедуре (например, коррекции);
  • Для связи с клиентом по указанному телефону (звонок, WhatsApp).

Данные не используются для рекламных рассылок и не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

3. Где хранятся данные

Данные хранятся в защищённой базе данных с ограниченным доступом. Соединение между сайтом и сервером шифруется (HTTPS). Доступ к данным имеет только мастер, к которому вы записались.

4. Хранение и удаление

Данные хранятся до тех пор, пока это необходимо для целей записи и обслуживания, либо до запроса клиента на удаление. Чтобы удалить свои данные из базы, свяжитесь с мастером по телефону, указанному на странице записи.

5. Согласие

Отправляя заявку на запись через сайт, вы соглашаетесь с обработкой указанных данных в целях, описанных выше, в соответствии с Федеральным законом №152-ФЗ «О персональных данных».

6. Контакты

По всем вопросам, связанным с обработкой персональных данных, обращайтесь по телефону мастера, указанному на странице записи.
